ARESAFIO — MENU PRINCIPAL BETA 3 — MINECRAFT JAVA 1.21.1

CLIENTE: Java 21 + Fabric Loader 0.16.14 o compatible + Fabric API para 1.21.1.

Si descargaste el artefacto completo de GitHub Actions, abre build/distributions/
y extrae ARESAFIO_MenuBeta3_1.21.1.zip. Dentro estan mods/ y resourcepacks/.

1. Cierra Minecraft. Retira de mods/ de TU CLIENTE los JAR anteriores:
   aresafio-menu-client-1.0.0-beta.1.jar y aresafio-menu-client-1.0.0-beta.2.jar.
2. Copia aresafio-menu-client-1.0.0-beta.3.jar a mods/ del cliente.
   Conserva una sola version del modulo de menus.
3. Sustituye el ZIP anterior de resourcepacks/ por el nuevo
   ARESAFIO_GUI_MenuBeta_ResourcePack.zip. Deja este ZIP comprimido.
4. En Minecraft: Opciones -> Paquetes de recursos -> activa la nueva copia del pack.
   Si conservaste otra copia con un nombre diferente, desactiva esa copia anterior.
5. Regresa al inicio para ver el menu actualizado.

El JAR de menu es solo de cliente. No reemplaza el JAR de servidor.
El servidor sigue utilizando el mod ARESAFIO GUI y el pack V1 originales.
El pack local beta incluye las fuentes y texturas originales de chat/TAB sin alterarlas.

BETA 3:
- Referencia 1920x1080. Logo del mismo tamano, desplazado 64 px a la izquierda.
- Cuatro botones un 10 % menores, centrados debajo del logo.
- Video completo adaptado de 1920x1024 a 1920x1080 sin recortar sus laterales,
  con Lanczos, enfoque moderado y JPEG 4:4:4 a 30 fps.
- Personalizacion y musica solo en el menu principal. Opciones, Multijugador,
  mundos, pausa y las demas pantallas conservan su interfaz y musica vanilla.

El video original H.264 ya tiene compresion: este ajuste no puede recuperar
el detalle que no exista en la fuente. Los PNG originales no se regeneran.

Para volver al inicio vanilla, desactiva el pack beta o retira el JAR del cliente.
